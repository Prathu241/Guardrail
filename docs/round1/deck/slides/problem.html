Problem & theme chosen

Agents propose actions that look right and aren't

issue_refund(order="O-5010")

No such order. The customer wrote O-5001; two digits were swapped.

"returns within 90 days"

A confident policy quote. The real policy says 30 days.

to="ada@exarnple.com"

One letter off the address on file. The customer's data leaves the company.

Why this problem

Every agent that moves money, sends messages or edits records needs this layer, and today it is usually one line in a prompt asking the model to be careful. A wrong refund or email cannot be taken back, so the check has to run before execution, against sources the model cannot talk its way around.

Theme 6: AI You Can Actually Trust · Problem 9: Catching an Agent Before It Acts on a Bad Idea

We picked Problem 9. Hallucinated tool calls are plausible: real-looking IDs, confident quotes, near-miss email addresses. They fail silently and their effects are irreversible.
