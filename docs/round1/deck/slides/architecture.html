Nothing changes outside the blue box. Payments and emails can't be rolled back, so the tool records them as intents and they are delivered only after the transaction commits.

ALLOW

Green, amber and red mark the three outcomes. Doubt (a timeout, malformed model output, a crashing check) never becomes ALLOW.

A proposed tool call passes a strict schema, 30 allowlist checks, a risk score and risk-routed model review. Blocked calls go back to the agent with the reason. Escalated calls wait for a person, and on approval go into the same write transaction as allowed ones. Inside that transaction everything is re-checked, the tool writes, and payments and messages are recorded as outbox intents. Providers are called only after commit.
