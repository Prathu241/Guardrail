Understanding of the challenge

What makes it hard

Wrong actions pass naive checks

A $129.99 refund on Ada's real order is valid on paper. It is the tent's price; she asked about the lantern. The check must compare against what the user asked, not only against the database.

No contradiction is not proof

A blocklist of known mistakes misses the next new one. Every value must be proven from a source, or a person decides.

Checking and doing must be one step

Records change between the check and the write, a retry can pay twice, and a sent email cannot be recalled.

The checker can be fooled too

An LLM judge reads the agent's arguments, so it can be prompt-injected through them, or approve on evidence it made up.

The crux: prove each action is grounded, atomically with executing it, without trusting the model that proposed it or the one that reviews it.

The surface prompt is "check the action against a source". The real difficulty is that hallucinations are usually valid-looking, the absence of a contradiction proves nothing, verification and execution must be atomic, and an LLM verifier is itself an attack surface.
